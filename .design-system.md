# Creative Multi-Tool Design System

## Core Aesthetic
- **Theme**: AMOLED Dark Mode. 
- **Backgrounds**: Pure `#000000` for main backgrounds, `#0A0A0A` for panels, `#1A1A1A` for borders.
- **Text**: Crisp white (`#FFFFFF`) for primary text, pure grayscale (`#A3A3A3` or `#737373`) for secondary.

## Layout & Grid
- **Spacing**: Strict 8px spacing grid. All margins, paddings, and gaps must be multiples of 8 (e.g., 8px, 16px, 24px, 32px, 48px, 64px, 96px, 128px).
- **Layout**: Centralized layout for main navigation and tool listing. Content visually anchored to the center to emphasize focus.

## Motion & Interaction
- **Staggered Animations**: Tool lists and grids must enter with smooth, staggered entrance animations (via `framer-motion`).
- **Premium Hover States**: Interactive elements must feature tactile micro-interactions (e.g., slight scaling, gradient reveals, icon nudges) without being obtrusive.
- **Performance Guidelines**: Rely strictly on GPU-accelerated properties (`transform`, `opacity`) for all motion to ensure buttery smooth rendering on 144Hz+ high-refresh-rate displays. Avoid animating properties that trigger layout thrashing (like `width`, `height`, or `margin`).
